# Audit 2026-11-26: the architecture as a whole

Read at c4469b50 against notes/coc-plan.md track T (T1, T1b, T2, TM1-TM3, T3a and T3b in place). Paths are under wap/
unless they start with notes/, wiki/, test/, lib/ or scripts/. "Probed": compiled by the tree's wap1, run by the native
wap (appendix 1).

## Target architecture

1. **Values** (R1): a name never sees a change made through another; a reference is a written `shared` cell.
2. **The front as today**: the data reader, the operator table, the rule engine, a grammar per module.
3. **One environment per module, as one value**: declaring gives a new environment or a refusal; a compiled module,
   the warm start and the seed carry that one format.
4. **One typer**, analyze, bidirectional: a type is a kernel term, and a node's facts are the typer's own.
5. **Trust at declarations** (R2): the kernel accepts each finished declaration, checked whole.
6. **What runs is made from what was accepted**: erase starts from the accepted terms and gives each value its layout
   row; the emitter has one case per form.
7. **Each word declared once** (R3), its host operation or layout beside it; a command prints what is believed.
8. **Tests are one command**, and every gate a step relies on is a script.

In place: 2, most of 4, the kernel of 5, and 6's rows. Missing: 1, 3 (grammars, the kernel's log, Signatures, the
type-term table and the warm state are apart), erase, 7, and 8's gates.

## Rewrites, ranked by what they buy

### R1. One memory model: a decision before T5

**Now.** The compiler shares; the plan is built on values.
- **Probed:** `zs = [1, 2]; ws = zs; ws#2 = 8; print zs` prints `[1, 8]`; `d = c; d += 3` changes c while
  `b = a + [2]` leaves a alone; a list or an instance a function changes is changed for its caller.
  types/lists.wap:46-49 shares on purpose.
- **The wiki says both:** wiki/list.md:222 shares ("Lists and maps are shared like instances"), pinned by
  test/test_lists_page.wap:28-31; wiki/Footguns.md:456-464 promises value semantics, naming two tests that exist
  nowhere. Both are warp's text, imported with its wiki; neither is a decision made for wap.
- **The compiler relies on sharing:** core/pipeline.wap:132-144 stores a Grammar and goes on growing it; the kernel
  changes its Environment and Checker through parameters (kernel/environment.wap:278-291, kernel/typing.wap:59-61).
  About 236 sites: 139 field writes and 73 in-place calls in core, 24 in the kernel.
- **The plan assumes values:** section 4 keeps "value semantics", section 2 makes a class a structure with eta, and 9.5,
  by which T5 makes statements terms, says `xs#i = v` and `p.x = v` "give the variable the updated value".
- **If T5 lands as planned**, `grown() := { xs = [1]; ys = xs; ys.add(2); xs }` returns `[1, 2]` (probed) while its
  term computes `[1]`: `law grown() == [1]` is proved, and the program breaks it.
- **Taking back has the same cause:** eleven mechanisms and seven saves undo state by hand, none in a `try` (appendix
  2). Two leak on a refusal: read_in's grammar (core/pipeline.wap:149-152, read on by `wap format` after it catches the
  refusal, compiler.wap:95-96) and a kind rule's round counter (core/rules/typed.wap:43-45).

**What the choice decides.** Under any model, 9.5's translation is believed (What the plan misses, 2). Where the
compiler cannot tell whether another name sees a write, values fall back to a copy (speed only, decided in erase or
emit, which 10.2 trusts for what runs), sharing to State (the function's laws cannot be proved).

**The options**, their lines known only after step 1:
- **(a) Values everywhere** (Hylo's mutable value semantics): a function that changes a parameter gives it back, 9.5's
  receiver rule for every parameter. Costs: in-place decided statically, since wasm GC counts no references (Swift and
  Lean 4 check at run time; Hylo's ownership discipline is far more than a few hundred lines); the cells 9.5 makes of
  written captured variables, `kept_if_given(e, () => …)` among them; persistent maps for the Environment, or each
  attempt copies the log; an id supply outside the value, or an old environment gives an id twice
  (notes/coc-t2.md:58); the 236 sites. Deletes about 90 (`mark`, `back_to`, the take-backs of `kept_if_given`,
  holes.wap and unify.wap, read_in's held grammar). Makes section 2, 9.5 and T2's row true, allows purpose.md's
  ownership inference "without changing source semantics", and freeing at a last use in a native build.
- **(b) Sharing, with State:** a write through a value another name may hold is State. Costs a may-alias analysis in
  the elaborator (about 200 lines in T5); every take-back stays; laws about functions that change a list go unproved.
- **(c) Data as values, instances as references** (Swift's split): (a)'s analysis for lists, maps and texts, while
  section 2's classes become cells; the Grammar and Environment are instances, so their take-backs stay.

**Leaning: (a)**, the only model where a weak analysis costs speed and never proofs, and the one purpose.md, section 2,
9.5, T2's row and Footguns.md assume; confirmed with step 1's count.

**Migration**, each step building itself:
1. One analysis lands, reporting only: a note for each write whose old value another name may still read. Over wap's
   own source it is the inventory, and every option's line count.
2. The user chooses; list.md, Footguns.md and test_lists_page.wap then say one thing.
3. (a) or (c): each reported site is rewritten to work under both rules (threaded, or a `shared` cell, which needs a
   seed refresh first); then the same analysis decides the copies in erase or emit, so behaviour changes only at
   reported sites, and a seed refresh carries it. (b): the analysis marks State in T5.
4. (a): the Environment becomes a value, with persistent maps and its own id supply; the take-backs go.
5. T5 builds on it.

**Risk:** high, and the spec's: programs relying on the other model change their results; compile time rises where
copies are made, measured by a stage-2 gate that is no script yet (What the plan misses, 7).

### R2. Trust at declarations, as the kernel is built: a user decision to revisit

**Now.** Section 13 records the user's decision (2026-11-25): "the kernel is the only maker of checked facts (LCF) …
the facts the stages write on nodes are those checked facts"; 5.1 and T2's row make a node's fact a judgement's number.
- **Built:** `declared` (kernel/typing.wap:169-181) judges each finished declaration whole, with a fresh checker. An
  elaboration's checker (core/analyze/holes.wap:37-40) memoizes for that elaboration only, every premise passing the
  elaborator's `filled_in` (kernel/typing.wap:29). A TYPE fact is a place in the compile's type-term table
  (core/type_notation.wap:83-84, 133), no judgement. This is Lean 4's model, and 10.1's "every term is checked whole".
- **Only the theory reaches the kernel:** no core file calls `declared`; holes.wap's `elaboration` is built by
  extensions/theory alone (elaborate/declare.wap:169, :262, read.wap:228); until T5 a function analyze typed enters as
  an opaque constant (T3's row).

**Target.** A declaration is trusted because the kernel accepted it whole; a node's facts are the typer's, untrusted.

**Deletes** no code, but unsized planned work: a judgement number on every node from T3 to T6 with its read-back rule,
and T3's soundness reason for typing once ("a discarded round would leave checked judgements behind"); typing once
stays, for speed. **Unblocks:** T3 to T6 each change the typer alone; a wrong fact refuses a good program at worst.

**Cost.** Each declaration is judged twice. If the stage-2 time trips, the remedy is the kernel's speed (interned terms,
10.5), never the elaboration's memo handed to `declared`: the memo outlives the take-backs, which leave `judged` alone,
and is asked before `constant_rule` checks a constant is live (kernel/typing.wap:23-33, 72-73), so it would accept a
term naming a constant taken back.

**Risk:** low in code; it revises a user decision, so it goes to the interviewer. It leaves the node-to-term gap open
(What the plan misses, 2).

### R3. One definition per word: a missing step at T5 to T7

**Now.**
- **Ten twins:** int's `+`, `*`, `==`, `<`, `<=`, `>`, `>=`, both `-`, and text's `+` are defined in the theory's
  prelude (extensions/theory/prelude/operators.wap:17-25, :33) and in the types module (types/prelude.wap:39-41, :58,
  :70-75; types/texts.wap:39), matched by their headers' shown text (extensions/theory/elaborate/declare.wap:358-359).
  Proofs read one body, the program runs the other; only a law run on values relates them. Nineteen more names
  (filter, add, count, keys, map, set, sum, text …) mean other things on each side.
- **31 `runs(…)` layouts**, 14 a `prim`; the 17 others are typed by core's typing, against T1's row ("no wap spelling
  of a host operation is typed or checked").
- **The trust base is a hand list** (notes/theory.md:314-341), already stale: :333 places text's `+` in
  types/text_bytes.wap, but it is wap code in types/texts.wap:39. T1's "listed by a command" has no command.
- **The bridge grows:** the theory work since T1 added 402 lines and deleted 110 (d3ad4b63, 245c4eb2, 84033ffd), no
  twin gone; T3g plans more, and T7 deletes it all.
- **The plan has the mechanism, not the step:** 9.7 lets a prelude function run by a `prim`, and section 13 attaches a
  leading `@runs` to its phrase (since d5757a4f, read by nothing). T3e moves the numbers prelude beside its twins,
  deleting neither, and T7's "now live once in wap/types" has no step.

**Target**, as Lean's `implemented_by`: a word is declared once, in wap/types; its definition is its meaning, checked
and unfolded by the kernel; `@runs` beside it names a `prim` of T1's table or a layout row, never a wap body; a `prim`
with no definition (`print`) stays opaque. A command prints the run bodies and layouts, with 9.7's other believed items
(a recursion as written, the kernel's shortcuts) and the warm state named beside them.

**Deletes about 120** (the twin match 31, `runs(…)` and its readers 50, one side of each twin 20, the hand list);
**adds about 45** (declare reading `@runs`, erase taking it, the command). **Unblocks** T7's "the words live once":
the bridge stops growing, and the believed list cannot drift.

**Migration:**
1. Declare reads `@runs`; a seed refresh carries it before the types module uses it.
2. The command lists every run body, a library's `prim` included (lib/bits.wap:23-29).
3. At T5 the twins become ten declarations in wap/types: the prelude's definition, the types module's `prim` as its
   `@runs`; `same_signature` goes. Not earlier: the prelude's `-` is `sum(a, minus(b))` over an inductive int.
4. Each of the nineteen names becomes one word or two: a word choice, through the interviewer.
5. The other `runs(…)` become annotations as their words move, by T7.

**Risk:** medium: step 3 changes `+` for every compile under the seed rule (the careful path) and brings theory
definitions into every compile. A run body that disagrees with its definition shows FAILED beside Proved, as today.

### What needs no rewrite

- **The reader:** Node holds as the one notation; a `use` line is still read twice (core/pipeline.wap:72-73).
- **The operator stage:** precedence as relations, aliases as rows, a table per module.
- **The rule engine and sugar:** patterns, matcher, templates and termination hold; hygiene is open.
- **Stages and facts:** under R2 facts need no trust. 18 walks per compile, and a new fact copies the fact list
  (wap/nodes.wap:80-87): an index once the stage-2 gate trips.
- **Types as terms (T3b):** one representation, compared by place; the ids need joining (misses 4).
- **The kernel:** Lean's rules, constants by id, i64 numbers with an overflow check; the budgets are 6.7's design.
- **The emitter:** T1b delivered; `primitive_code` still dispatches 18 ways (core/emit/primitives.wap:65), against T1's
  "one lookup"; the build branches and its own typing go with erase.
- **The seed loop:** holds; its bootstrap is written twice, and the copies differ (test/wap/compile.sh:51 empties the
  warm state before wap0, scripts/refresh-seed.sh:41 keeps it).
- **The extensions:** native, c, wasm and prove hold; the theory shrinks by T3 to T7.

## What the plan misses

1. **The memory model** (R1), to be chosen before T5.
2. **The node-to-term gap.** 9.7: "Each constant runs by its statements as written, the ones the emitter reads." The
   kernel accepts a term the elaborator made of them by 9.5. Their agreement is elaborator code, which 10.2 trusts for
   neither column, yet its second ("a proved law holds for the running program") rests on it. Either erase starts from
   the accepted terms, or 10.2 lists 9.5's translation as believed.
3. **Where trust sits** (R2): the plan numbers a judgement on each node; the kernel checks declarations whole.
4. **Two id spaces for one constant:** `TYPES.words` numbers type words from 1 (core/type_notation.wap:83-90), and so
   does the kernel's log. Before T3e or T3f hand such a term to the kernel, they must be one (10.4, "two terms taken
   for one").
5. **Two nats:** the kernel types a numeral as an inductive `enum nat { zero; successor(n: nat) }`
   (kernel/typing.wap:106, kernel/numbers.wap:54); T3e makes a numeral an `int` with no term for it; T4 makes `nat` be
   `int where it >= 0`. The plan should say: the kernel's nat is the types module's inner carrier, an `int` numeral is `int.of_nat` of it, and
   the subset is the `nat` programs write.
6. **T2's row against its sub-plan:** the row says the environment is persistent, "so a refused statement needs no
   rollback"; notes/coc-t2.md chose one changed in place and taken back. R1 (a) makes the row true; else it should say
   what is built.
7. **The gates are not scripts**, though notes/backbone.md wants them "measured by a script, never by eye":
   - nothing checks "`--stage 2` a fixed point", which accepts every T step: test/wap/test_self.sh:38-47 only times,
     scripts/refresh-seed.sh:70 only reports;
   - the speed shares of notes/coc-t3.md and notes/agents/integrator.md:88's +20% have no script;
   - a `_wanted` file that does not compile is one line of test/reds.txt: 94 of them hide 496 checks.
8. **`int` wraps until T8**, for good under cut 9: 10.2's second column should carry section 13's exception.
